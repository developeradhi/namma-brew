## 📌 Overview

**Namma Brew** is a bleeding-edge web application that blends an artisanal South Indian café brand with an intelligent **Autonomous Campaign Operating System (`CampaignGuard AI`)**.

Built specifically for Bengaluru's vibrant café culture, the platform solves the critical marketing and operational challenges faced by local F&B business owners:
1. **Interactive Café Discovery**: Immersive digital café storefront featuring steam micro-animations, authentic South Indian breakfast bites (*Thatte Idli*, *Crispy Medu Vada*), single-origin filter coffees, and community reviews.
2. **Zero-Hallucination AI Marketing**: A deterministic **10-Step Campaign Operating System** that converts informal owner briefs into multi-channel marketing campaigns (WhatsApp, Instagram, Email, Social) while strictly locking business facts, prices, and locations to eliminate AI hallucinations.

### 🛡️ CampaignGuard AI: 10-Step Campaign Engine

The centerpiece of **Namma Brew** is the end-to-end autonomous campaign builder located at `/campaign`:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        CAMPAIGNGUARD AI ENGINE                         │
├───────────────┬────────────────────────┬───────────────────────────────┤
│ 01. Brief Ingestion     │ 02. Interactive Clarify│ 03. Hard Fact Lock           │
│ 04. Hyperlocal Targeting│ 05. Strategy Blueprint │ 06. AI Generative Engine     │
│ 07. Compliance Audit    │ 08. Predictive ROI     │ 09. Channel Optimization     │
│                         │ 10. Multi-Channel Launch                       │
└───────────────┴────────────────────────┴───────────────────────────────┘
```

1. **Step 01 — Intelligent Business Brief**: Ingests natural-language promotional ideas (e.g., *"Weekend Filter Coffee + Thatte Idli 20% combo for techies in Indiranagar"*).
2. **Step 02 — Interactive Clarifications**: Surfaces AI-driven probing questions to establish campaign duration, budget thresholds, and discount validity.
3. **Step 03 — Hard Fact & Guardrail Lock**: Establishes immutable boundaries separating editable creative copy from strictly locked business facts (pricing, operational hours, outlets).
4. **Step 04 — Hyperlocal Geo-Targeting**: Granular demographic and zone selection across Bengaluru tech corridors (Indiranagar, Koramangala, HSR Layout, Whitefield).
5. **Step 05 — Omni-Channel Strategy Blueprint**: Auto-allocates optimal marketing spend across Instagram Stories/Reels, WhatsApp Broadcasts, and Email.
6. **Step 06 — AI Creative Generation**: Synthesizes high-converting copy, headlines, emojis, and visual prompts tailored for Bengaluru audiences.
7. **Step 07 — Self-Healing Compliance Audit**: Automatically validates generated copy against locked facts. Flagged inaccuracies or hallucinated claims trigger silent self-correction.
8. **Step 08 — Predictive ROI & Resonance Analytics**: Interactive Recharts visualizations displaying estimated reach, conversion rate, customer footfall, and return on ad spend (ROAS).
9. **Step 09 — Channel-Specific Formatting**: Fine-tunes character lengths, hashtag density, and tone for WhatsApp vs. Instagram vs. Facebook.
10. **Step 10 — One-Click Omni-Channel Launch**:
   - 📲 **WhatsApp Direct Dispatch**: Formatted messages sent directly to subscriber groups.
   - 📸 **Instagram Quick-Publish**: Automatically copies formatted caption, hashtags, and CTA to the clipboard and redirects directly to [@namma_.brew on Instagram](https://instagram.com/namma_.brew).
   - ✉️ **Email & Facebook Integration**: Instant export of generated campaign assets.

> *Note: For technical evaluators and developers running this repository locally.*

### Prerequisites
- **Node.js**: `v20.x` or higher
- **Package Manager**: `npm` (v10+), `pnpm`, or `yarn`

### Setup Commands
```bash
# 1. Clone repository
git clone https://github.com/developeradhi/namma-brew.git
cd namma-brew

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

### Available Scripts
| Command | Purpose |
| :--- | :--- |
| `npm run dev` | Runs local dev server on `http://localhost:3000` with Turbopack |
| `npm run build` | Compiles optimized production bundle |
| `npm run start` | Boots production server |
| `npm run lint` | Runs ESLint validation |

### Public Mobile Testing (ngrok)
```bash
ngrok http 3000
```
